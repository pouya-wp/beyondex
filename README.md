## ✦ Overview

**Beyondex** is an avant-garde enterprise platform designed to coordinate, deploy, and interact with autonomous AI agents through an award-winning web interface. Built on Next.js 15 and React 19, it combines 3D canvas rendering (Three.js), fluid physics-based gestures (Framer Motion & Lenis), and global payment orchestrations (Stripe, Zarinpal, NOWPayments).

---

## ⚡ Key Features

- **Fluid 3D Spatial Canvas**: Real-time WebGL agent visualizer and neural activity monitor powered by Three.js.
- **Bilingual Infrastructure (FA / EN)**: Native Right-to-Left (RTL) and Left-to-Right (LTR) localization with automatic direction-aware typography.
- **Autonomous Agent Hub**: Multi-modal workflows orchestrating code synthesis, task scheduling, and live monitoring.
- **Enterprise Multi-Rail Checkout**: Unified payment abstraction layer integrating domestic (ZarinPal) and international (Stripe, NOWPayments crypto) transactions.
- **Cinematic Micro-Interactions**: Custom inertia scrolling with Lenis and layout transitions tuned for 120 FPS display fidelity.
- **Search Engine & AI Discovery Engine**: Dynamic JSON-LD schema builder and bilingual OpenGraph generators.

- **Framework**: [Next.js 15 App Router](https://nextjs.org/)

## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- npm / pnpm / yarn

### Installation

```bash
# Clone repository
git clone https://github.com/pouya-wp/beyondex.git
cd beyondex

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the live workspace.

### Production Build

```bash
npm run build
npm run start
```
